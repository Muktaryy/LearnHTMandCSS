# HTML Basics

## English

### Document Structure
- `<!DOCTYPE html>` tells the browser the document uses HTML5.
- `<html>` contains the whole HTML document.
- `<head>` contains information about the webpage.
- `<title>` sets the browser tab title.
- `<body>` contains visible webpage content.

Structure:
`<!DOCTYPE html>` → `<html>` → `<head>` + `<body>`

### Headings
- `<h1>` = main heading.
- `<h2>` = major section.
- `<h3>` = subsection.
- `<h4>` = deeper subsection.
- `<h5>` = next deeper level.
- `<h6>` = deepest level.

Hierarchy:
`h1 → h2 → h3 → h4 → h5 → h6`

### Text
- `<p>` = paragraph.
- `<strong>` = important text.
- `<em>` = emphasized text.
- `<span>` = small wrapper for part of a sentence; it does not normally change appearance by itself.

### Line Breaks
- `<br>` = forces a new line.
- `<hr>` = creates a horizontal divider.
- There is no standard `<vr>` tag for a vertical line; CSS is normally used for vertical lines.

### Links
- `<a>` = link.
- `href` = where the link goes.
- `target="_blank"` = opens the link in a new tab.

## Somali

### Qaab-dhismeedka HTML
- `<!DOCTYPE html>` wuxuu browser-ka u sheegaa in document-ku yahay HTML5.
- `<html>` wuxuu hayaa document-ka HTML oo dhan.
- `<head>` waxaa lagu kaydiyaa xogta ku saabsan webpage-ka.
- `<title>` wuxuu magaca ka dhigaa browser tab-ka.
- `<body>` wuxuu hayaa waxyaabaha webpage-ka ka muuqda.

Qaab-dhismeedka:
`<!DOCTYPE html>` → `<html>` → `<head>` + `<body>`

### Cinwaannada
- `<h1>` = cinwaanka ugu weyn.
- `<h2>` = cinwaan qayb weyn.
- `<h3>` = qayb-hoosaad.
- `<h4>` = qayb-hoosaad ka sii hooseysa.
- `<h5>` = heer ka sii hooseeya.
- `<h6>` = heerka ugu hooseeya.

Kala sarreynta:
`h1 → h2 → h3 → h4 → h5 → h6`

### Qoraalka
- `<p>` = qayb qoraal ah.
- `<strong>` = qoraal muhiim ah.
- `<em>` = qoraal la xoojinayo.
- `<span>` = wrapper yar oo lagu duubo qayb qoraal ah; kaligiis muuqaalka badanaa ma beddelo.

### Khadadka
- `<br>` = qoraalka wuxuu geliyaa line cusub.
- `<hr>` = wuxuu sameeyaa xariiq jiif ah oo kala qaybisa content-ka.
- Ma jiro `<vr>` tag HTML oo caadi ah; CSS ayaa badanaa loo isticmaalaa xariiqyada taagan.

### Links
- `<a>` = wuxuu sameeyaa link.
- `href` = wuxuu sheegaa meesha link-gu aadayo.
- `target="_blank"` = wuxuu link-ga ku furayaa tab cusub.
